## 🚀 启动与使用方式

### 方式一：双击直接打开（最简单）
- 双击目录下的 `start.bat`；
- 或者直接用任意浏览器（Edge、Chrome、Firefox 等）双击打开 `index.html` 即可！

### 方式二：本地 HTTP 服务（可选）
如果您希望通过本地服务器访问，可以在当前目录下打开终端运行：
```bash
python -m http.server 8000
```
然后在浏览器中访问 [http://localhost:8000](http://localhost:8000)。
